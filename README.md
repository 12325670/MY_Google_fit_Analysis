# 🧠 Google Fit Data Analysis – Personal Health Tracker with Python

This project showcases how I analyzed my own physical activity data exported from **Google Fit** using **Python**, **Pandas**, **Matplotlib**, and **Seaborn**.

## 📌 Overview
 I was curious to see my health habits in numbers. This project answers questions like:

- How active am I during weekdays vs weekends?
- What is my average walking and biking time?
- What trends can I find across months and years?
- How does my physical activity correlate with other factors?

## 🔧 Tools Used
- Python
- Jupyter Notebook
- Pandas, NumPy
- Matplotlib, Seaborn
- Google Fit (Data Export)

## 📊 Visualizations
- 📅 Weekday vs Weekend activity breakdown
- 🗓️ Yearly walking distance comparison
- 🔥 Pairplots & Heatmaps to show correlation
- 🧘‍♂️ Daily physical activity summaries

## 🚀 How to Run
1. Clone the repository  
2. Open `GoogleFit_Analysis.ipynb` in Jupyter/Colab  
3. Make sure the CSV is placed inside `data/` folder  
4. Run the notebook to see results!
